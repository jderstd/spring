# JDER Spring

A response builder for Spring.

## Installation

For POM, add the dependency to `pom.xml`:

```xml
<dependency>
    <groupId>io.github.jderstd</groupId>
    <artifactId>spring</artifactId>
    <version>x.x.x</version>
</dependency>
```

For Gradle, add the dependency to `build.gradle`/`build.gradle.kts`:

```gradle
dependencies {
    implementation("io.github.jderstd:spring:x.x.x")
}
```
